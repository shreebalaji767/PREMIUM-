# PREMIUM™
A polished fake SaaS subscription experience that slowly becomes completely absurd.

## Stack
- Static HTML
- CSS
- Vanilla JavaScript
- localStorage
- No backend
- No database
- No real payments

## GitHub Pages
Enable **Settings → Pages → Deploy from branch → main → / (root)**.

All user state is stored locally in the browser under `premium-chaos-v1`.

The site deliberately rotates random outcomes so refreshes and interactions can produce different absurd events.
